# Instituto Ponte do Saber — Site Institucional

Site estático de ONG fictícia para fins educacionais.

## 📁 Estrutura

- `*.html` → páginas do site
- `assets/css/` → folhas de estilo
- `assets/js/` → scripts
- `assets/img/` → imagens e logos
- `assets/docs/` → PDFs institucionais

## 🚀 Como usar

1. Clone ou baixe o projeto.
2. Abra `index.html` no navegador.
3. Navegue pelo menu.

## 🛠️ Tecnologias

- HTML5 semântico
- CSS3
- JavaScript (vanilla)
- Bootstrap 5 (via CDN)
- Bootstrap Icons

## 📌 Funcionalidades

- Menu responsivo (Bootstrap)
- Máscaras de CPF, telefone e CEP
- Validação nativa HTML5 + Bootstrap
- Validação real de CPF (dígito verificador)
- Integração com ViaCEP
- Página de agradecimento com mensagem personalizada
